CONCLUSION
===============================================================================================

WINNER: Gemma3-Kurisu-4B NVFP4 (fine-tuned)

Key Metrics:
  - Emotion tag accuracy: 100.0% (30/30)
  - Average response time: 1.11s (fastest of all models)
  - GPU memory: 3.5 GiB (smallest footprint)
  - Natural Kurisu character voice with ツンデレ personality
  - Consistent [TAG] format - no parsing edge cases
  - No prefix hack needed (unlike Nemotron DPO)

Why Gemma3-Kurisu-4B NVFP4 wins:
  1. Perfect emotion tag compliance (100.0%)
  2. Fastest response time (1.11s) — even faster than Ollama gemma3:4b (1.51s)
  3. Smallest GPU footprint (3.5 GiB) — fits easily on any GPU
  4. Rich, natural Kurisu character voice from SFT+DPO fine-tuning
  5. NVFP4 quantization: 2.2x speedup over BF16 with zero quality loss

Fine-tuning pipeline:
  - Base: google/gemma-3-4b-it
  - SFT: 5 epochs, LoRA r=32, 1137 Kurisu dialogue examples
  - DPO: 3 epochs, LoRA r=16, 1451 preference pairs (tag accuracy + character style)
  - NVFP4: modelopt quantization, 8GB → 3.2GB model size
  - Total training time: ~60 min on DGX Spark (Blackwell GPU)

Previous winner (Ollama vanilla): gemma3:4b
  - Still excellent for zero-shot (100% emotion, 1.51s)
  - But lacks Kurisu's specific character voice and personality
  - Fine-tuned version is faster AND has character depth

Thinking vs No-Thinking findings:
  - Thinking does NOT improve quality for RP/chat tasks
  - Conclusion: Disable thinking for roleplay chat tasks
